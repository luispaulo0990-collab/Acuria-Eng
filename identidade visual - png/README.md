# ACURIA · Identidade Visual em PNG

Pasta de arquivos exportados em alta resolução (**PNG 300+ DPI / Retina @2x**) para uso institucional, digital, redes sociais e materiais de apresentação.

---

## 📁 Estrutura de Pastas

```
identidade visual - png/
├── 01-logotipos-principais/       # Assinaturas horizontais (com e sem slogan)
├── 02-logotipos-verticais/         # Assinaturas verticais centralizadas
├── 03-simbolos-e-icones/           # Isotipo isolado, favicons e app icons
├── 04-submarcas/                   # Arquitetura de submarcas (Decide, Estima, Orça, etc.)
├── 05-redes-sociais/               # Capa LinkedIn, avatares de perfil e posts Instagram
└── 06-paleta-e-especificacoes/     # Pranchas da paleta cromática e resumo visual
```

---

## 🎨 Guia de Aplicação dos Arquivos

### 1. `01-logotipos-principais/` (Assinatura Horizontal)
* **`acuria-logo-horizontal-dark.png`**: Versão completa com fundo Azul Grafite Profundo (`#0A111E`). Ideal para apresentações escuras e cabeçalhos escuros.
* **`acuria-logo-horizontal-light.png`**: Versão completa com fundo branco (`#FFFFFF`). Ideal para documentos impressos e apresentações claras.
* **`acuria-logo-horizontal-transparente-escuro.png`**: Fundo transparente com tipografia escura. Aplique sobre fotos claras ou superfícies brancas/cinzas.
* **`acuria-logo-horizontal-transparente-claro.png`**: Fundo transparente com tipografia branca. Aplique sobre fundos escuros, fotos escuras ou texturas.
* **`acuria-logo-horizontal-monocromatico-branco.png`**: Versão negativa 100% branca sobre fundo transparente.
* **`acuria-logo-horizontal-monocromatico-grafite.png`**: Versão monocromática 100% grafite sobre fundo transparente.
* **`acuria-logo-sem-slogan-*.png`**: Versões sem a frase *"Inteligência de Custos"*, ideais para locais com espaço horizontal reduzido.

### 2. `02-logotipos-verticais/` (Assinatura Vertical / Secundária)
* Ideal para crachás, uniformes, capas de relatórios A4, totens, banners verticais e rodapés centrados.
* Disponível nas versões: **Dark**, **Light**, **Transparente Claro**, **Transparente Escuro** e **Monocromáticas**.

### 3. `03-simbolos-e-icones/` (Isotipo Geométrico)
* **`acuria-simbolo-transparente.png`**: Símbolo em ultra-alta resolução com corte em Verde Esmeralda e fundo transparente.
* **`acuria-simbolo-fundo-escuro.png`** / **`...-fundo-claro.png`** / **`...-fundo-branco.png`**: Quadrados perfeitos para avatares, carimbos ou marcas d'água.
* **`acuria-simbolo-esmeralda.png`**: Símbolo preenchido integralmente na cor de destaque.
* **`favicon-512x512.png`**, **`192x192.png`**, **`32x32.png`**: Ícones prontos para navegadores web e PWA.
* **`apple-touch-icon-180x180.png`**: Ícone com cantos arredondados no padrão Apple iOS.

### 4. `04-submarcas/` (Arquitetura de Produtos e Serviços)
* **`acuria-decide-*`**: Engenharia de valor e cenários de custo (carro-chefe).
* **`acuria-estima-*`**: Estimativas paramétricas e viabilidade para concepção de novos negócios.
* **`acuria-orca-*`**: Orçamento analítico e executivo com diagnóstico técnico.
* **`acuria-control-*`**: Gestão e controle de variações orçamentárias.
* **`acuria-data-*`**: Inteligência e benchmarking histórico de indicadores de custos.

### 5. `05-redes-sociais/` (Kit Social)
* **`linkedin-capa-1584x396.png`**: Capa institucional pronta para Company Page do LinkedIn com grid de dados.
* **`avatar-perfil-400x400-dark.png`** e **`...-light.png`**: Foto de perfil para LinkedIn, Instagram e WhatsApp Business.
* **`instagram-post-frase-1080x1080.png`**: Post quadrado de posicionamento institucional.
* **`instagram-post-indicador-1080x1080.png`**: Post quadrado de estudo de caso com indicador métrico.

### 6. `06-paleta-e-especificacoes/`
* **`acuria-paleta-de-cores.png`**: Prancha de referência cromática com códigos HEX, RGB, CMYK e Pantone das 3 cores primárias.
* **`acuria-cartao-marca-resumo.png`**: Resumo de alto padrão comparando aplicações principais.
